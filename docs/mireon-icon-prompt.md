# Prompt para el icono de Mireon

Diseña un icono de aplicación premium y minimalista para **Mireon - Private Media**, una galería multimedia local, privada y offline para fotografías y vídeos.

Usa un símbolo abstracto y reconocible que combine una mirada sutil, un marco de galería y una sensación de protección, sin dibujar una cámara literal ni usar texto. Estética elegante, limpia y contemporánea; formas geométricas suaves, composición centrada, pocos elementos y excelente legibilidad en tamaños pequeños. Paleta sobria con negro grafito, marfil y un acento verde esmeralda profundo. Fondo sólido o degradado casi imperceptible, sin mockup de teléfono, sin fotografías, sin interfaz, sin sombras excesivas, sin estilo genérico de galería y sin referencias visuales a Apple Photos o Google Photos. Entregar una versión cuadrada, equilibrada, de alto contraste, adecuada para Android e iOS.
